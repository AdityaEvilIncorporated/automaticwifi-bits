# Accounts and services

Generated by bs-env.py. During the build everything below runs locally and needs no account.
Only the last column is for you, at Gate 2, when you deploy.

| Service | Local stand-in during the build | Needed for production (you, at Gate 2) |
| --- | --- | --- |
| Database | Postgres 17 in Docker, database `app`, a fresh test database per task | a managed Postgres (Neon, Supabase, RDS, ...) and its DATABASE_URL |
| App users | admin and test users created by scripts/seed.sh from ADMIN_* and TEST_USER_* in .env | create the real admin on the live site |
| mail | Mailpit (catches every email; web UI and API on MAILPIT_URL) | an email provider account (e.g. Resend, Postmark, SES) and a verified sending domain |
| storage | SeaweedFS S3 API on S3_ENDPOINT (any key works locally) | an S3-compatible bucket (AWS S3, Cloudflare R2, ...) and an access key limited to that bucket |
| Code hosting | GitHub repo, or a local remote until you create it (`repo ready <name>`) | the GitHub repo |
